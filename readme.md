# 🎴 Yu-Gi-Oh Jo-Ken-Po Edition

Um mini game inspirado no universo de Yu-Gi-Oh!, utilizando a mecânica clássica de Pedra, Papel e Tesoura com cartas icônicas do anime.

O projeto foi desenvolvido com HTML, CSS e JavaScript puro, focando em:

- Manipulação de DOM
- Responsividade
- Efeitos visuais
- Interatividade
- Áudio e vídeo
- Organização de estado da aplicação

---

## 🚀 Demonstração

O jogador escolhe uma carta e enfrenta o computador em um duelo estilo Jo-Ken-Po:

- 🐉 Blue Eyes White Dragon → Paper
- 🧙 Dark Magician → Rock
- 👑 Exodia → Scissors
